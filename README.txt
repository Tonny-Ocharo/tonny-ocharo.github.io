# Tonny Blair Ocharo — Professional Portfolio

A responsive, single-page portfolio website built with HTML, CSS and vanilla JavaScript.

## Open locally
1. Extract the ZIP file.
2. Open the `tonny_professional_portfolio` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Before publishing — personalise these details
- Your email, phone number and LinkedIn profile have been added to the contact section.
- Add your GitHub profile URL when you have one.
- Add exact employment dates and confirm the employer names/job titles.
- Add the exact IBM course/certificate title and completion date.
- Add project screenshots, GitHub repository links and demos when ready.
- Add your CV PDF to this folder (for example `Tonny_Ocharo_CV.pdf`) and add a download link in the hero section if you want a CV download button.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a public repository named `yourusername.github.io`.
3. Upload the contents of this folder (not the ZIP itself).
4. In the repository, open **Settings → Pages**.
5. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. After deployment, your site will be available at `https://yourusername.github.io`.
